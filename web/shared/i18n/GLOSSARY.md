# Translation glossary

Use these terms everywhere. German addresses the user with **du** (informal, lower-case: du, dein, dich); French uses
**vous**. Keep the tone short and friendly; no exclamation marks.

Keep as they are in every language: KeePort, KeePass, KeePassXC, KeePass2Android, KeePassium, WebDAV, TOTP, KDBX,
ETag, CSRF, URL, HTTPS, Have I Been Pwned, the action tags of the audit log (e.g. `LoginFailed`), file names and
anything the user typed or that comes from a vault (entry titles, folder names such as "Recycle Bin" stored in the KDBX).
